## 📦 How to Download APKs from GitHub Actions

Anyone visiting this repository can download the ready-to-install debug APK for **each practical** directly from GitHub:

1. Click on the **[Actions](../../actions)** tab at the top of this GitHub repository.
2. Select the latest run under **"Build All Practicals APKs"**.
3. Scroll down to the **Artifacts** section at the bottom of the summary page.
4. Click on any practical artifact to download the `.zip` file containing the installable `.apk`:
   - `Practical1-apk`
   - `Practical2-apk`
   - `Practical3-apk`
   - `Practical4-apk`
   - `Practical5-apk`
   - `Practical6-apk`
   - `Practical7-apk`
   - `Practical9-Spendly-apk`
5. Unzip the downloaded file and install the APK on your Android device or emulator!

## 🛠️ How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Sky1234323/MAD---Mobile-Application-Devlopement.git
   ```
2. Open **Android Studio**.
3. Choose **Open** and select the specific practical directory you want to run (e.g. `Practical1` or `Practical9 - Spendly`).
4. Allow Gradle to sync dependencies.
5. Select your target device / emulator and click **Run** (`Shift + F10`).
